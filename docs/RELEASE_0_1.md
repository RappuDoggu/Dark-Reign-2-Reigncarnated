# Reigncarnated 0.1

Dark Reign 2 for Android. [Download the APK and source](https://github.com/RappuDoggu/Dark-Reign-2-Reigncarnated/releases/tag/v0.1).

## Included

- Instant Action with the original AI, map/difficulty selection and practice mode.
- JDA and Sprawler campaign starts, plus individual mission and cutscene selection.
- Touch controls for selection, orders, group selection, building placement/rotation and map pan.
- Music, speech, unit voices and combat audio from imported game files.
- Android audio/display settings, game-data import/export and diagnostics.
- Optional player-only starting resources in Instant Action.

## Install

Requires Android 8.0 or newer, ARM64 and GLES 3.0. Install the APK, then import
complete game data from your PC installation. The APK does not include game data.
See the [player guide](PLAYER_GUIDE.md) for the required folders and controls.

For updates, install over the existing app. Do not uninstall or clear app data
unless you have backed up your imported files and progress.

## Known issues

- Both campaigns still need complete start-to-finish testing. Some dialogue and transitions may fail.
- Some textures, fog of war, lighting and effects need fixes.
- Mid-mission save/resume and multiplayer are not available.
- Performance and audio can vary by device, especially in longer matches.

Individual mission selection does not guarantee every mission can be completed.

## Planned

Multiplayer, mod management, more maps, upscaling, improved zoom/camera controls,
save/resume and controller support. See the [roadmap](ROADMAP.md).

## Bug reports and source

Include your device, Android version, app version, mission/map and steps to
reproduce the issue. Attach the in-app diagnostics ZIP collected after the problem.
Keep game archives out of public reports.
