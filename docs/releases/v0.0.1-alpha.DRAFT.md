## Included

Native ARM64 offline Instant Action with original AI, original menu animation,
Android audio/display/touch settings, native campaign mission/cinematic startup,
mission speech decoding and background music arbitration. The main menu provides
original campaign starts plus direct mission/cutscene tests without progression
locks. Individual tests use separate progress. Instant Action resources can be
edited for the local player only; AI stockpiles remain map-defined.

Updates APK22–30's existing IA City Test installation using the same signer.
Game data must be imported separately from a legally owned installation. Keys,
owned asset packs and private diagnostics are excluded from release assets.

## Known limitations and testing scope

This is an unfinished offline preview. Complete campaigns are not yet verified;
local mid-mission save/restore is not implemented; active-texture NaN UV rendering
defects remain; broad device, long-session and final dialogue acceptance remain.
Multiplayer and PC crossplay are not implemented. The 31-entry catalog and host
navigation fixtures do not prove that the original objectives are completable.

Host validation: 68 general tests, 16 campaign-selection/16 resource-input checks,
retained touch/report/music checks, native session validation, original campaign
handoff and individual-return fixtures twice. Real original IA setup checks local
44,444 / AI 20,000, local 0 / AI 20,000 and map-default 20,000 / 20,000 before the
first simulation cycle, with clean ASan shutdown. No APK31 phone FPS claim.
