## Restore

1. Retrieve the project development branch from the private GitHub repository.
2. Download the two private archives above, or have the Library integration
   materialize their exact Library IDs. These links require the owning account.
3. Verify both SHA-256 checksums before extraction.
4. Extract the source archive outside the project repository. Set
   `REIGN_UPSTREAM` to the extracted `darkreign2-9ce9da5` directory.
5. Extract the installation separately. Keep proprietary assets outside Git and
   APK packages. Use a separate new writable directory for native user profiles.
6. Follow `LOGIN_PROFILE_PORT.md` for the latest tested build/probe commands.
   Follow checked-in Android setup/package tools for NDK builds.

No access to the original desktop is required for these inputs. The additional
medwards repository is a reference, not the source revision used for this build.
